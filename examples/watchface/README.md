# Browser Demo watchface

Standalone Pebble SDK project targeting Emery. Uses system fonts, minute ticks, battery and
connection services, and an AppMessage status from PebbleKit JS. Build with the official
Pebble SDK (`pebble build`) in this directory. The browser build/install pipeline is not
implemented yet. This source is not the ARM framebuffer diagnostic shown by the workbench.

Source validation status is recorded in the repository status document. Do not claim this
watchface runs in the browser until it is installed and executed in real emulator firmware.
