Checked 2026-09-16. A retail product, an SDK app platform, a firmware board revision, and an emulator machine are different identifiers. Sharing an SDK platform does **not** make two firmware images interchangeable.

The current officially published watch lineup names 2 Duo, Time 2 and Round 2. Pebble Index 01 is also a published current **ring**, using a microphone, button and companion app; it is not one of the seven Pebble watch SDK platforms. An Index emulator would be a separate board/protocol project. No speculative future watches or internal prototype codenames are presented as retail products.

The 2016 and current Time 2 both use the Emery app platform and 200×228 pixels. Their CPUs, firmware boards, boot dependencies, devices and firmware images differ. The generic QEMU Emery model deliberately uses an ARM Cortex-M33 and simple virtual MMIO; it does not model the physical Star-MC1/SiFli SoC.

Firmware revision lists are identifiers present in primary source, not a claim that every revision shipped or that all revisions are electrically identical. In particular the official app distinguishes retail models through color/manufacturing identity while its firmware platform enum lists hardware revisions. Do not infer compatibility solely from a marketing name or SDK platform.

## Generic profiles implemented

All three use 4 MiB internal ROM, 32 MiB mapped SPI storage, 128 KiB guest framebuffer aperture, three UARTs, two timers, RTC, GPIO, and a nominal 64 MHz clock. These are emulator contracts, not physical watch specifications.

| ABI ID / profile  | QEMU CPU identity            | SRAM    | Guest framebuffer                                | Features                  |
| ----------------- | ---------------------------- | ------- | ------------------------------------------------ | ------------------------- |
| 1 / `qemu_flint`  | Cortex-M4, CPUID `410fc240`  | 256 KiB | 1bpp, LSB first, 20-byte padded rows, 3360 bytes | Audio; no touch           |
| 2 / `qemu_emery`  | Cortex-M33, CPUID `410fd213` | 512 KiB | ARGB2222, 200-byte rows, 45600 bytes             | Audio and touch           |
| 3 / `qemu_gabbro` | Cortex-M33, CPUID `410fd213` | 512 KiB | ARGB2222, 260-byte rows, 67600 bytes             | Round and touch; no audio |

All browser presentation buffers are canonical ARGB2222, `width*height` bytes. Flint converts its packed guest pixels on completed UPDATE; Gabbro leaves outside-circle bytes intact so host clipping cannot change guest state or oracle comparisons.

The shared Rust instruction engine executes the common M4/M33 instruction set. Selecting Flint changes identification, devices and memory, but currently does not enforce all M4 architecture exclusions. Peripheral timing, physical radios, sensor analog behavior and power draw are not established by these functional QEMU tests. The full physical-firmware path remains a separate required milestone.
